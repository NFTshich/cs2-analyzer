====================================================================
 РАЗДЕЛ А. ЧТО УМЕЕТ CS2 ANALYZER (возможности бота)
====================================================================

CS2 Analyzer — это локальный веб-аналитик матчей Counter-Strike 2.
Работает полностью на твоём компьютере (ничего в интернет кроме
скачивания статистики не отправляет). Управление — через браузер.

ОСНОВНЫЕ ВОЗМОЖНОСТИ:

1. ПРОГНОЗ МАТЧА
   - выбираешь 2 команды и карту;
   - бот считает вероятность победы каждой команды в процентах;
   - показывает, кто фаворит;
   - показывает УРОВЕНЬ УВЕРЕННОСТИ модели:
     * если модель уверена (>65%) — жёлтое/зелёное уведомление;
     * если шансы близки к 50/50 — предупреждение «данных мало /
       шансы примерно равны». Прогноз всё равно показывается,
       но ты видишь, что он ненадёжный.

2. ФОРМА КОМАНД
   - графики winrate команд за последние матчи;
   - кумулятивный winrate и скользящее среднее за 10 матчей.

3. КАРТЫ
   - насколько хорошо команда играет на каждой карте (heatmap);
   - на каких картах чаще всего играют (pick rate).

4. BACKTEST
   - как модель «отработала» на прошедших матчах;
   - сколько раз предсказала правильно (accuracy).

5. АВТООБНОВЛЕНИЕ ДАННЫХ
   - пока бот запущен, раз в час сам проверяет Liquipedia;
   - докачивает новые сыгранные матчи;
   - если появились новые — сам переобучает модель.
   (никаких действий от тебя не требуется)

6. ПРОГНОЗ ВНУТРИ МОДЕЛИ (как считает)
   Бот учитывает: ELO-рейтинг команд, форму последних матчей,
   winrate на конкретной карте, личные встречи (h2h), силу
   соперников, тир турнира.

СЛОВАРЬ ТЕРМИНОВ (для новичков):
  - winrate — доля побед (например, 60% = 6 побед из 10).
  - карта — одна из локаций CS2 (Mirage, Inferno, Dust2 и т.д.).
  - BO1 / BO3 / BO5 — формат серии: 1/3/5 карт.
  - фаворит — команда, которая по модели вероятнее победит.

ВАЖНО О ТОЧНОСТИ (честно):
  Киберспортивные матчи очень непредсказуемы. Даже лучшие платные
  модели дают точность 60–70%. Воспринимай проценты как ОЦЕНКУ,
  а не как гарантию победы.


====================================================================
 РАЗДЕЛ Б. КАК ЗАПУСТИТЬ НА ЭТОМ КОМПЬЮТЕРЕ
====================================================================

ПРОСТОЙ СПОСОБ (двойным кликом):
  1. Открой папку: C:\Users\skrob\OneDrive\Рабочий стол\CS2_ANALYZER
  2. Дважды кликни по файлу: Запуск_CS2_Анализатора.bat
  3. Останется открытым чёрное окно (CMD) — НЕ закрывай его.
  4. Подожди ~10 секунд, откроется браузер с адресом:
     http://localhost:8501
  5. Остановка бота: в чёрном окне нажми Ctrl+C, потом закрой окно.

РУЧНОЙ СПОСОБ (через командную строку):
  1. В папке проекта в адресной строке проводника введи: cmd
     и нажми Enter — откроется командная строка внутри папки.
  2. Активируй окружение. ВВЕДИ ровно эту строку и нажми Enter:
     .venv\Scripts\activate
     (слева в строке появится (.venv))
  3. Запусти бота. ВВЕДИ и нажми Enter:
     python -m streamlit run app.py
  4. Открой в браузере: http://localhost:8501
  5. Остановка: Ctrl+C в командной строке.

ПОКА ЧЁРНОЕ ОКНО ОТКРЫТО — БОТ РАБОТАЕТ.
Закрыто окно = бот выключен.


====================================================================
 РАЗДЕЛ В. КАК ПОСТАВИТЬ НА ДРУГОЙ КОМПЬЮТЕР (с нуля)
====================================================================

Этот раздел — если хочешь запустить CS2 Analyzer на другом ПК.
Выполняется по шагам, сверху вниз. Ориентировочно 10–20 минут.


---------- ШАГ В1. ПРОВЕРИТЬ УСТАНОВЛЕН ЛИ PYTHON ----------

1) На новом компьютере открой командную строку:
   - нажми клавишу Win (флажок Windows),
   - набери: cmd
   - нажми Enter.

2) В открывшемся окне введи и нажми Enter:
   python --version

   Одно из двух:
   а) покажет "Python 3.11.x" или "Python 3.12.x" → ПЕРЕЙДИ К ШАГУ В2.
   б) пишет «не является внутренней или внешней командой» или
      открывает магазин Microsoft Store → Python нет или не в PATH.
      Тогда иди к ШАГУ В1.1.

---------- ШАГ В1.1. УСТАНОВИТЬ PYTHON (если его нет) ----------

1) Открой сайт: https://www.python.org/downloads/
2) Нажми кнопку "Download Python 3.12" (или новее).
3) Запусти скачанный установщик.
4) ВАЖНО: поставь галочку внизу окна установщика:
     [x] Add Python to PATH
   (БЕЗ этой галочки Python не заработает из командной строки!)
5) Нажми "Install Now" и дождись завершения.
6) Закрой и заново открой командную строку (cmd).
7) Снова проверь: python --version  → должно показать версию.
   Теперь можно идти к ШАГУ В2.


---------- ШАГ В2. СКОПИРОВАТЬ ПРОЕКТ НА НОВЫЙ КОМПЬЮТЕР ----------

1) Скопируй папку проекта (по флешке/диску/облаку/сети) на новый ПК.
2) Положи её туда, где удобно. РЕКОМЕНДАЦИЯ (важно):
   в пути к папке НЕ должно быть русских букв. Например:
     C:\CS2Analyzer            ← хорошо
     C:\Users\<имя>\Desktop\CS2_ANALYZER  ← хорошо
     C:\Рабочий стол\CS2\_ANALYZER        ← плохо, могут быть сбои

3) В ПЕРЕНОСИМОЙ папке ДОЛЖНЫ БЫТЬ эти файлы:
     app.py
     requirements.txt
     .env.example
     Запуск_CS2_Анализатора.bat
     src/        (папка с кодом)
     tests/      (папка с тестами)
     data/       (папка с данными — можно НЕ копировать, соберутся сами)
     models/     (папка с моделью — можно НЕ копировать, переобучится)

4) Папку .venv НЕ копируй — она «привязана» к конкретному
   компьютеру. Если она всё же переехала — просто удали её
   на новом ПК (правой кнопкой -> Удалить).


---------- ШАГ В3. ОТКРЫТЬ КОМАНДНУЮ СТРОКУ В ПАПКЕ ПРОЕКТА ----------

1) Открой папку проекта в проводнике (там, куда скопировал).
2) В АДРЕСНОЙ СТРОКЕ проводника (сверху, там где путь)
   набери: cmd
   и нажми Enter.
   Откроется командная строка, уже внутри папки проекта.
   (Проверь: перед командой стоит путь к твоей папке.)


---------- ШАГ В4. СОЗДАТЬ ВИРТУАЛЬНОЕ ОКРУЖЕНИЕ ----------

В командной строке проекта введи по очереди эти команды,
каждую заканчивая Enter:

Команда 1 — создать окружение:
   python -m venv .venv

(пауза ~10-30 секунд; появится папка .venv)

Команда 2 — активировать его:
   .venv\Scripts\activate

(перед строкой появится (.venv) — значит сработало)

Команда 3 — обновить pip (установщик пакетов):
   python -m pip install --upgrade pip

Команда 4 — установить все библиотеки бота (2–5 минут):
   pip install -r requirements.txt

Если всё прошло без красных ошибок — переходи к ШАГУ В5.


---------- ШАГ В5. СОБРАТЬ ДАННЫЕ (первый запуск на новом ПК) ----------

На новом компьютере данные пустые. Один раз собери реальные
матчи с Liquipedia (нужен интернет). ВВЕДИ ПО ОЧЕРЕДИ:

Команда 1 — скачать ~2000+ матчей (5–10 минут):
   python -m src.scraper

Команда 2 — построить признаки:
   python -m src.features

Команда 3 — обучить модель:
   python -m src.model

(Если ты скопировал папки data/ и models/ со старого ПК —
   этот шаг можно пропустить, данные уже есть.)


---------- ШАГ В6. ЗАПУСТИТЬ БОТА НА НОВОМ ПК ----------

СПОСОБ 1 — двойной клик:
   Дважды кликни по файлу: Запуск_CS2_Анализатора.bat
   Через ~10 сек откроется браузер.

СПОСОБ 2 — вручную (из командной строки проекта, где уже (.venv)):
   python -m streamlit run app.py
   затем открой в браузере: http://localhost:8501

Остановка бота: Ctrl+C в командной строке.


---------- ШАГ В7. (НЕОБЯЗАТЕЛЬНО) УБРАТЬ ЗАПРОС EMAIL ----------

При самом первом запуске Streamlit может спросить:
   Email:
Это запрос на подписку от Streamlit (не от нашего бота).
Просто нажми Enter, ничего не вводя.

Чтобы убрать навсегда, создай файл по пути:
   C:\Users\<ИМЯ_ПОЛЬЗОВАТЕЛЯ>\.streamlit\config.toml
(Если папки .streamlit нет — создай её вручную.)
Содержимое файла:
   [browser]
   gatherUsageStats = false

   [server]
   headless = true


====================================================================
 ПРИЛОЖЕНИЕ 1. ЧАСТЫЕ ОШИБКИ НА НОВОМ ПК И КАК ПОЧИНИТЬ
====================================================================

1. «python не является внутренней или внешней командой»
   → Python не в PATH. Переустанови с галочкой «Add Python to PATH»,
     перезапусти cmd, повтори ШАГ В4.

2. Windows блокирует скрипты ("запуск скриптов отключен"):
   → выполни разово:
     powershell -ExecutionPolicy Bypass -File .venv\Scripts\Activate.ps1
   (файл Запуск_CS2_Анализатора.bat работает и без этого)

3. «ModuleNotFoundError: No module named ...»
   → не установлены библиотеки. Выполни:
     pip install -r requirements.txt

4. «Address already in use» (порт занят):
   → запусти с другим портом:
     python -m streamlit run app.py --server.port 8502

5. Бот запустился, но не показывает матчи / долго думает:
   → проверь интернет и что ШАГ В5 прошёл без ошибок
     (файл data/raw/matches.csv не пуст).

====================================================================

CS2_ANALYZER\
│   app.py                  ← главный файл бота (веб-интерфейс)
│   requirements.txt        ← список библиотек для установки
│   .env.example            ← пример настроек (необязательный)
│   Запуск_CS2_Анализатора.bat ← ярлык запуска двойным кликом
│   Инструкция_по_запуску.txt  ← этот файл
│
├── src\                    ← код бота (Python)
│   ├── config.py           ← настройки (пути, турниры, автообновление)
│   ├── scraper.py          ← скачивание матчей с Liquipedia
│   ├── liquipedia.py       ← работа с API Liquipedia
│   ├── features.py         ← расчёт признаков (форма, карты, h2h, ELO, SOS)
│   ├── model.py            ← обучение модели
│   ├── predictor.py        ← предсказание матча
│   └── autorefresh.py      ← автообновление раз в час
│
├── data\
│   ├── raw\matches.csv     ← база сырых матчей (растёт сама)
│   └── processed\          ← обработанные данные
│
├── models\                 ← обученная модель (model.pkl)
└── tests\                  ← автоматические тесты
